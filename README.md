Official companion repository for **CropKD-Net** (**Paper 2** of the CropGuard Research Ecosystem), investigating feature- and logit-level knowledge distillation plus INT8 post-training quantization from the CropGuardNet teacher onto sub-100K edge backbones evaluated across the leak-free 35,420-image benchmark.

Code and quantized ONNX checkpoints will be released here alongside manuscript submission.
