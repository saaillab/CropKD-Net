CropKD-Net: Edge Knowledge Distillation Study

CropKD-Net is an ongoing edge-compression study by Innocent Nyalala exploring sub-100K student distillation from the CropGuardNet multi-crop CNN-Transformer teacher across the 35,420-image deduplicated leaf pathology benchmark.

For full benchmarks, deduplication manifests, XAI attribution maps, and PyTorch/ONNX code, visit the parent CropGuardNet project page and repository.
